REST API системи управління енергетичним обладнанням


Практична робота №4 з дисципліни «Основи веб-програмування»


________________________________________________________________________________________________________________________________________________________________________________
Опис проєкту:

Проєкт присвячений розробці архітектури RESTful API для автоматизації обліку та моніторингу високовольтних вимикачів у межах енергетичної системи. Система дозволяє централізовано керувати технічними даними обладнання, відстежувати параметри номінальної напруги, струму та кількість спрацювань для планування технічного обслуговування.


________________________________________________________________________________________________________________________________________________________________________________
Ключові особливості:

Повнофункціональний RESTful API: реалізація методів GET, POST, PUT та DELETE для повного керування реєстром обладнання.

Система збору статистики: вбудовані механізми відстеження кількості запитів до API (API Stats) для аналізу навантаження на систему.

Серверна валідація: сувора перевірка вхідних даних на рівні бекенду (перевірка типів, обов'язкових полів та логічних меж технічних характеристик).

Централізована обробка помилок: використання Middleware для перехоплення помилок та відправки стандартизованих JSON-відповідей (Error Handling).

Інтеграція CORS: налаштована політика доступу до ресурсів, що дозволяє безпечно взаємодіяти з API з різних доменів.


________________________________________________________________________________________________________________________________________________________________________________
Технологічний стек:

Backend: Node.js (платформа), Express.js (фреймворк для маршрутизації та Middleware).

Middleware & Tools: CORS (обробка крос-доменних запитів), Nodemon (автоматичне перезавантаження сервера при розробці).

Data Management: обробка даних у форматі JSON, програмна логіка валідації та фільтрації масивів об'єктів.


________________________________________________________________________________________________________________________________________________________________________________
Структура репозиторію:

Проєкт побудований за стандартами розробки серверних додатків на Express:

server.js — ядро системи: ініціалізація сервера, підключення проміжних обробників, логіка валідації validateBreakerData та опис усіх маршрутів API.

public/ — клієнтська частина (за наявності):

index.html — інтерфейс для тестування запитів.

style.css — стилізація елементів відображення даних.

script.js — логіка взаємодії з API через асинхронні запити.

package.json — маніфест проєкту: опис залежностей (express, cors), версії та скрипти для запуску системи (start, dev).

Для розгортання системи на локальному комп'ютері необхідно:

Переконатися у наявності встановленого Node.js.

Завантажити файли проєкту та перейти в кореневу папку через термінал.

Виконати команду npm install для завантаження бібліотек (Express, CORS).

Запустити сервер командою npm start або node server.js.

API буде доступне за адресою http://localhost:3000 (або вказаним у конфігурації портом).
