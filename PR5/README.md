Моніторинг якості електроенергії

Практична робота №5 з дисципліни «Основи веб-програмування»

Опис проєкту:

Проєкт присвячений розробці клієнтського веб-додатку для моніторингу якості електроенергії з використанням JavaScript та REST API. Система імітує роботу пункту вимірювання якості електроенергії та дозволяє в режимі реального часу відображати основні параметри електричної мережі.

У застосунку реалізовано контроль відхилення напруги, коефіцієнта несиметрії, коефіцієнта спотворення синусоїдальності THD, флікера та частоти. Дані автоматично оновлюються кожні 2 секунди, після чого клієнтська частина отримує їх із сервера, обробляє та відображає у вигляді карток, таблиці, графіків і кольорових індикаторів відповідності нормам.

Ключові особливості:

Клієнтський веб-додаток JavaScript + API: реалізовано взаємодію клієнтської частини з сервером через REST API для отримання поточних показників якості електроенергії.

Оновлення даних у реальному часі: сервер генерує нові вимірювання кожні 2 секунди, а інтерфейс автоматично оновлює показники без перезавантаження сторінки.

Візуалізація форми сигналу напруги: побудовано лінійний графік, який показує зміну миттєвого значення напруги в часі з урахуванням гармонічних спотворень.

Спектральний аналіз гармонік: реалізовано стовпчасту діаграму для відображення основної та вищих гармонік у відсотках від основної гармоніки.

Таблиця показників якості: додано таблицю з поточними значеннями параметрів, одиницями вимірювання, допустимими межами та станом кожного показника.

Індикатори відповідності нормам: кожен параметр автоматично перевіряється на відповідність допустимим межам і позначається статусом «Норма» або «Порушення».

Технологічний стек:

Backend: Node.js (платформа), Express.js (фреймворк для маршрутизації та Middleware).

Middleware & Tools: CORS (обробка крос-доменних запитів), Nodemon (автоматичне перезавантаження сервера при розробці).

Data Management: обробка даних у форматі JSON, програмна логіка валідації та фільтрації масивів об'єктів.

Структура репозиторію:

Проєкт побудований за стандартами розробки серверних додатків на Express:

power_quality_monitoring_v11/
│
├── package.json
├── server.js
│
└── public/
    ├── index.html
    ├── styles.css
    ├── api.js
    ├── charts.js
    └── app.js

Де:

server.js — серверна частина проєкту: ініціалізація Express-сервера, генерація показників якості електроенергії, формування сигналу напруги, розрахунок гармонік, збереження історії вимірювань та опис REST API endpoints.

public/ — папка з клієнтською частиною веб-додатку.

index.html — основна HTML-сторінка застосунку, яка містить структуру інтерфейсу, блоки карток, таблицю, canvas-елементи для графіків та індикатори відповідності нормам.

styles.css — файл стилів для оформлення сторінки, карток показників, таблиці, статусів та індикаторів.

api.js — модуль для виконання асинхронних запитів до REST API: отримання поточних даних, історії вимірювань і стану сервера.

charts.js — модуль візуалізації, який створює та оновлює графік форми сигналу напруги і стовпчасту діаграму гармонік.

app.js — основна логіка клієнтської частини: отримання даних з API, оновлення карток, таблиці, індикаторів, графіків і статусу підключення.

package.json — маніфест проєкту: опис залежностей, версії, назви проєкту та команд запуску.


API endpoints

У проєкті реалізовано такі основні REST API endpoints:

GET /api/quality/current

Повертає поточні показники якості електроенергії, форму сигналу напруги, масив гармонік та індикатори відповідності нормам.

GET /api/quality/history

Повертає історію останніх вимірювань.

GET /api/status

Повертає інформацію про стан сервера, об’єкт моніторингу, час роботи сервера та час останнього оновлення даних.
