# Портал управління розумною енергомережею Smart Grid

Практична робота №6 з дисципліни «Основи веб-програмування»

## Опис проєкту

Проєкт присвячений розробці захищеного веб-додатку для порталу управління розумною енергомережею міста Smart Grid. Система імітує роботу інформаційного порталу для контролю інтелектуальної енергетичної мережі, у якій різні користувачі мають різні рівні доступу до функцій керування та аналізу.

У застосунку реалізовано реєстрацію користувачів, вхід у систему, роботу із сесіями, розмежування доступу за ролями, захист API-endpoints та базові механізми веб-безпеки. Система підтримує три ролі: operator, analyst та administrator.

Оператор може переглядати баланс енергомережі та виконувати коригування балансу. Аналітик має доступ до перегляду балансу та прогнозів. Адміністратор може змінювати системну конфігурацію та переглядати журнал подій безпеки.

## Ключові особливості

### Реєстрація та вхід користувачів

У системі реалізовано реєстрацію нових користувачів із введенням ПІБ, email, пароля, повтору пароля та вибором ролі. Під час входу використовується Passport.js з локальною стратегією автентифікації.

### Ролі користувачів

У проєкті реалізовано три ролі:

- operator — оператор, який контролює баланс мережі;
- analyst — аналітик, який переглядає баланс і прогнози;
- administrator — адміністратор, який налаштовує систему.

### Захист API

Кожен захищений endpoint перевіряє, чи користувач увійшов у систему та чи має він потрібну роль. Для цього використано middleware автентифікації та RBAC.

### Хешування паролів

Паролі користувачів не зберігаються у відкритому вигляді. Для їх захисту використовується bcryptjs.

### Валідація даних

Дані, які вводить користувач, перевіряються за допомогою express-validator. Перевіряється формат email, складність пароля, збіг пароля з повтором, допустимість ролі та коректність даних у формах.

### Захист від XSS

У застосунку реалізовано санітизацію введених даних і використано Helmet.js для встановлення HTTP-заголовків безпеки та Content Security Policy.

### Rate limiting

Для захисту від brute-force атак реалізовано обмеження кількості спроб входу за певний проміжок часу.

### Real-time intrusion detection

У навчальному форматі реалізовано middleware для виявлення підозрілих запитів. Якщо система знаходить небезпечні шаблони, подія записується до журналу безпеки.

### Anomaly detection в логінах

Система фіксує невдалі спроби входу, входи з нових IP-адрес і нетипову активність користувача.

### IP whitelisting

Для критичних операцій, таких як коригування балансу мережі та зміна системної конфігурації, використовується перевірка дозволених IP-адрес.

### Mandatory password rotation

У системі зберігається дата останньої зміни пароля. Також реалізовано endpoint для зміни пароля користувачем.

## Технологічний стек

### Backend

- Node.js — середовище виконання JavaScript;
- Express.js — фреймворк для створення сервера та API;
- Passport.js — автентифікація користувачів;
- passport-local — локальна стратегія входу через email і пароль;
- express-session — робота із сесіями користувача;
- bcryptjs — хешування паролів;
- express-validator — валідація введених даних;
- express-rate-limit — обмеження кількості запитів;
- Helmet.js — встановлення HTTP-заголовків безпеки;
- CORS — налаштування політики крос-доменних запитів;
- dotenv — робота зі змінними середовища.

### Frontend

- HTML;
- Bootstrap;
- JavaScript;
- Fetch API.

### Data Management

- JSON-файли для навчального зберігання користувачів;
- audit.log для журналювання подій безпеки.
