Веб-система  моніторингу енергосервісних контрактів "ДержЕнергоСервіс"

Практична робота №3 з дисципліни «Основи веб-програмування»

Опис проєкту

Опис проєкту
Проєкт являє собою інтерактивний веб-інтерфейс (Registry Dashboard) для обліку та моніторингу енергосервісних контрактів (ЕСКО). Система автоматизує процес реєстрації договорів, дозволяючи централізовано зберігати дані про замовників, об'єкти модернізації, фінансові показники та очікувану енергоефективність.

Ключові особливості:

Інтерактивне керування даними: реалізація повного циклу CRUD (створення, читання, видалення) для записів про контракти.

Клієнтська валідація: інтелектуальні форми з перевіркою коректності введених даних (позитивні значення вартості, межі відсотка економії).

Серверна обробка: асинхронна взаємодія з сервером на базі Node.js для збереження даних у персистентне сховище.

Динамічний рендеринг: автоматичне оновлення списку активних договорів на сторінці без її перезавантаження завдяки Fetch API.

Адаптивний UI: інтерфейс у стилі Dark Mode, побудований на сучасних CSS-технологіях (Grid, Flexbox), що коректно відображається на будь-яких пристроях.

Технологічний стек
Frontend: HTML5 (семантична верстка), CSS3 (Custom Properties, темна тема).

Backend: Node.js (середовище виконання), Express.js (фреймворк для побудови RESTful API).

Робота з даними: Fetch API (асинхронні запити), File System (fs/promises) для роботи з JSON-базою, модуль Crypto для генерації UUID.

Структура репозиторію

index.html — основна структура дашборду та модальних вікон.

css/styles.css — стилізація інтерфейсу, логіка темної теми та анімації статусів.

script/script.js — логіка обробки даних, керування графіками та інтерфейсом.

images/ — графічні матеріали та логотипи.

sounds/ — аудіофайли для системи тривожного сповіщення.
